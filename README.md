# DIBS CAT ($DIBSCAT)

"I sat on it. It's mine now."

Static one-page site, no build step. Open `index.html`.

- Settings (first `<script>`): `CONTRACT`, `TWITTER`, `BUY_URL`. BUY stays disabled until `BUY_URL` is set.
- Mini-game THE SIT: balance the cat on the map pin while owners try to shoo him (broom / spray / leaf blower / treat). 8 places.
- THE MAP: claimed places appear as pins; click an empty spot to drop your own pin.
- All sound and music are Web Audio, no audio files.
